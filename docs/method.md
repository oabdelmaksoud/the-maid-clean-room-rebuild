# Working method

Start with one meaningful user workflow and its failure boundaries. Define which sources and observations are permitted, then capture versioned evidence using original synthetic inputs. Keep documented, observed, reported, and unknown claims distinguishable. Record proposed design separately.

Use the portable [skill](../skills/behavior-rebuild/SKILL.md) for the complete mode instructions. Its [evidence reference](../skills/behavior-rebuild/references/evidence-levels.md) explains classification; its [handoff reference](../skills/behavior-rebuild/references/handoff-boundaries.md) defines the exposure and review boundary.

Distill approved observations into behavioral contracts. Choose commands and architecture independently, with state, error, cancellation, retry, and persistence semantics. Freeze original fixtures, assertions, and oracles before testing. Retain output artifacts and individual trial results. Evaluate feature breadth separately from dependable real-work outcomes.

When a case fails, record a reproducible gap, its user impact, owner, and recovery acceptance condition. Prioritize harm and exposure before effort. Preserve the failed evidence and rerun affected cases after repair. A separate reviewer evaluates completion.

## Session continuity

Before resuming, confirm the workspace/revision, current status, owned files, accepted packet identity, unresolved source decisions, and ranked gaps. Assign bounded tasks with explicit file ownership and acceptance conditions. At a checkpoint, record changes, actual commands/results, blockers, and the next reproducible action. Concurrent agents must integrate and test the combined result; separate successful task reports do not establish combined correctness.

## Original worked example

Delimited Notebook is a fictional CSV workflow. Its specification and synthetic data are authored for this kit. It teaches how to carry a contract into cases and records; it is not evidence about another product. The example's own README states what is executable and what remains illustrative.
